## Deploy

Upload the contents of this folder directly to the root of:

`christofferbidemark/christofferbidemark.github.io`

GitHub Pages settings:
- Source: Deploy from a branch
- Branch: main
- Folder: /(root)

Live URL:
https://christofferbidemark.github.io/
